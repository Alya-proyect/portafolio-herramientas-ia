# Comandos que aprendí

| Comando | Para qué sirve |
| Comando | Descripción | Ejemplo de uso |
| :--- | :--- | :--- |
| `cd` | Cambia el directorio actual de la terminal. | `cd ~/portafolio-herramientas-ia` |
| `git pull` | Descarga los cambios más recientes desde el repositorio remoto y los combina. | `git pull origin main` |
| `git add` | Añade los archivos modificados al área de preparación (staging). | `git add .` |
| `git commit` | Registra los cambios en el historial con un mensaje descriptivo. | `git commit -m "Agrega documentación"` |
| `git push` | Sube los commits locales al repositorio remoto en GitHub. | `git push origin main` |
| `git clone` | Descarga una copia completa de un repositorio remoto a la computadora. | `git clone https://github.com` |
